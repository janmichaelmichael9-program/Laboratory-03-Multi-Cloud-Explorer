# Google Cloud Platform (GCP) Research

## Brief Overview
GCP is Google’s public cloud platform, launched in 2008. Built on the same infrastructure that powers Google Search, YouTube, and Gmail. It leads in containers, Kubernetes, and AI/ML.

## Global Infrastructure
- 34 **Regions** across the globe
- Fiber network with one of the fastest backbones
- Single-region or multi-region deployment options

## Cloud Management Console
- Clean interface at: https://console.cloud.google.com
- Project-based organization structure
- Built-in Cloud Shell and API explorer

## Four Core Services
1. **Google Compute Engine** — Virtual machines in Google’s data centers
2. **Google Cloud Storage** — Unified object storage
3. **Google VPC** — Global virtual private cloud
4. **Google BigQuery** — Serverless, petabyte-scale data warehouse

## Three Advantages
- Industry-leading Kubernetes and container support
- Strongest AI/ML tools and data analytics
- High-performance, cost-effective networking

## Typical Enterprise Use Cases
- Cloud-native and microservices applications
- AI, machine learning, and data analytics
- Scalable apps for global users
- Startups and open-source tech companies
