## Analysis Questions

### 1. Which cloud provider offers the broadest range of services?
**AWS** offers the widest range—over 200 services across every category. Its massive ecosystem covers legacy to cutting-edge tools, giving it the most options for any workload or industry.

### 2. Which provider best integrates with Microsoft technologies?
**Microsoft Azure** is designed to work natively with Windows Server, Microsoft 365, Active Directory, and .NET. Authentication, licensing, and management feel seamless for Microsoft shops.

### 3. Which provider is strongest in Artificial Intelligence and Kubernetes?
**Google Cloud Platform** pioneered Kubernetes and builds AI/ML tools directly into its core offerings. Products like Vertex AI and BigQuery make it the natural choice for AI-first workloads.

### 4. Which cloud platform would you personally choose and why?
I would choose **GCP** for new projects. Its clean interface, Kubernetes leadership, and performance make it ideal for modern applications. If I were migrating an existing Windows enterprise, I would choose Azure.
