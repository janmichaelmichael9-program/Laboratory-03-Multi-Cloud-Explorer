# Microsoft Azure Research

## Brief Overview
Azure is Microsoft’s cloud platform, launched in 2010. It provides IaaS, PaaS, and SaaS, with strong native integration with Windows, Active Directory, and Microsoft 365.

## Global Infrastructure
- 60+ **Regions** worldwide
- Available in more countries than any other cloud
- Paired regions for disaster recovery

## Cloud Management Console
- Unified portal at: https://portal.azure.com
- Drag-and-drop dashboard, all services in one view
- Built-in Azure CLI and Cloud Shell access

## Four Core Services
1. **Azure Virtual Machines** — Windows & Linux virtual servers
2. **Azure Blob Storage** — Massively scalable object storage
3. **Azure Virtual Network** — Secure private network in Azure
4. **Azure SQL Database** — Fully managed SQL database

## Three Advantages
- Seamless integration with Microsoft ecosystem
- Strong hybrid cloud and on-premises connectivity
- Best for Windows Server and enterprise identity environments

## Typical Enterprise Use Cases
- Migrating Windows Server workloads
- Enterprise apps using .NET and Microsoft SQL
- Hybrid cloud with Active Directory
- Government and institutional compliance
